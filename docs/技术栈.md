# 前后端技术架构分析报告

基于 `efm-ai-agent-service` 和 `vue3_vite_pinia` 项目的完整技术分析。

---

## 一、项目概述

| **项目类型定位**     |          |                                                            |
| -------------------- | -------- | ---------------------------------------------------------- |
| efm-ai-agent-service | 后端服务 | AI Agent服务，提供智能问答、财报数据分析、现金流分析等能力 |
| vue3\_vite\_pinia    | 前端应用 | EurekaX卡片应用，提供AI对话界面和财报卡片展示              |

## 七、开发规范要点

### 7.1 后端规范

- **分层规范**: facade → agent → tool → service → client
- **命名规范**: 类名大驼峰，方法名小驼峰，常量全大写下划线分隔
- **异常处理**: 统一异常封装，使用Jalor异常处理机制
- **日志规范**: 使用Log4j2，按模块分级记录

### 7.2 前端规范

- **组件规范**: SFC单文件组件，`<script setup>`语法
- **样式规范**: Less预处理器，Scoped CSS隔离
- **代码规范**: ESLint + Prettier，TypeScript类型检查
- **国际化**: 词条key格式 `模块.功能.描述`
